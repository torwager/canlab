# CANlab website

The website of the Cognitive and Affective Neuroscience Lab (Tor Wager, Dartmouth College):
**https://torwager.github.io/canlab/** (to be mirrored at canlab.science).

It replaces the WordPress site at sites.dartmouth.edu/canlab and keeps all of its content, restyled after
[scienceofplacebo.org](https://scienceofplacebo.org), with a searchable tagged publication database, reading lists and
reference export, a collaborator map, bibliometrics, sign-in, and an automated daily search for new papers.

- **Static site** in `site/` (no build step for the HTML; JSON data and pre-rendered paper pages are generated by `pipeline/build_site.py` into `site/data/` and `site/papers/`).
- **Data** as plain JSON in `data/`: `papers.json` (the bibliography, 400+ records with links, abstracts, citation counts and tags), `people.json`, `research.json`, `news_posts.json`, `resources.json`, `join.json`, plus `candidates.json` / `screened.json` written by the daily search and `news.json` by the news search.
- **Tags** on three axes (`pipeline/taxonomy.json`): topic, approach, article type. The initial tagging was done from the full text of each paper (PDF) where available and from the abstract otherwise; see `pipeline/prompts/classify.md`.
- **Daily search** (`.github/workflows/daily.yml`): OpenAlex author works + PubMed author query, LLM tagging, a review queue (`data/candidates.json`), citation refresh, site rebuild and deploy.
- **News** every two days (`.github/workflows/news.yml`): Google News RSS + Apple podcast search, optional LLM relevance filter.
- **Google Form monitor** (`.github/workflows/form.yml`, every 30 minutes): reads the form's response sheet (published as CSV, stored in the `FORM_CSV_URL` secret) and opens a GitHub issue for every new response, which emails the repository owner.
- **Community API** (`worker/`): a Cloudflare Worker with GitHub OAuth sign-in and KV storage for synced stars and named reading lists.
- **PDFs** live in the repository under `site/pdf/<paper id>.pdf` (served by GitHub Pages at `/canlab/pdf/<id>.pdf`). PubMed author-manuscript versions that have not yet been replaced by the publisher version are kept in `site/pdf/author_manuscripts/`. The GitHub release `pdfs` holds the original files from the old site as a backup.

## Local use

```bash
pip install -r requirements.txt
python -m pipeline.build_site                 # writes site/data, site/papers, feed.xml, sitemap.xml
(cd site && python -m http.server 8765)       # http://localhost:8765
```

Editing content: change the JSON files in `data/` (people, research themes, news posts, resources, openings) and push; the
site rebuilds and deploys automatically. Paper records live in `data/papers.json`; tags, `summary`, `key_finding` and
`free_keywords` can be edited by hand and survive re-tagging.

```bash
python -m pipeline.run_daily --days 30 --dry-run     # try the search locally (needs an LLM key for tagging)
python -m pipeline.approve --list                     # review queue
python -m pipeline.approve <id> [<id>...]             # promote candidates into papers.json
python -m pipeline.news --no-llm                      # news search without the LLM filter
```

## One-time setup after cloning to a new GitHub account

1. **Pages**: Settings → Pages → Source "GitHub Actions". The daily workflow deploys `site/`.
2. **Secrets** (Settings → Secrets and variables → Actions): `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` (tagging and the news filter; without a key the daily search still runs and queues untagged candidates), optionally `OPENALEX_API_KEY` and `NCBI_API_KEY` (higher rate limits). Variables: `CANLAB_CONTACT_EMAIL` (polite-pool email for OpenAlex/PubMed), `CANLAB_LLM_MODEL` (default `claude-sonnet-5` / `gpt-5-mini`).
4. **Sign-in and synced lists**: follow `worker/README.md` (about 10 minutes: a GitHub OAuth app, a Cloudflare KV namespace, `wrangler deploy`), then set `communityApi` in `site/assets/config.js`.
5. **Analytics**: create a site in Cloudflare Web Analytics (free, cookie-free) for `torwager.github.io` and paste the token into `cfAnalyticsToken` in `site/assets/config.js`. Cloudflare's dashboard shows visits, pages, referrers and countries.
6. **Form monitor**: in the Google Form choose Responses → Link to Sheets; in the sheet, File → Share → Publish to web → the responses tab as CSV; store the published URL as the `FORM_CSV_URL` repository secret. New responses then arrive as GitHub issues (label `form-response`) within 30 minutes.
7. **Search engines**: submit `https://torwager.github.io/canlab/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## Tagging papers

`scripts/make_tag_bundles.py` prepares batches (title, abstract, first 14k characters of the PDF text and keyword-in-context
snippets) for tagging; `scripts/apply_tags.py` writes the resulting JSON back into `data/papers.json`. The daily pipeline tags
new candidates automatically with `pipeline/classify.py` (Anthropic or OpenAI, structured JSON output against
`pipeline/schemas/llm_output.schema.json`).
